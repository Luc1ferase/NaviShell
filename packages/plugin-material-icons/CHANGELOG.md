# Changelog

## 0.1.0 (2026-10-22)

- First release: a file icon theme for the file manager built from the Material Icon Theme
  SVGs - 144 icons chosen by exact file name, name prefix, extension or folder name, with
  icons for PyTorch checkpoints, ONNX models, CUDA sources, notebooks and conda
  environments. Switches the file manager to the theme on its first run; the choice then
  lives under Settings → Appearance → File icons.
